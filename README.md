# 🏅 Olympic Data Analytics using Azure Synapse Analytics

## 📅 Duration
**March 2024**

## 📌 Project Overview
This project explores the capabilities of **Azure Synapse Analytics** by analyzing the 2021 Olympic dataset. I utilized a variety of Azure services to extract, transform, and analyze data, showcasing the efficiency of cloud-based data engineering and analytics pipelines within the Synapse ecosystem.

## 🧰 Tools & Technologies
- **Azure Synapse Analytics**
- **Azure Data Lake**
- **Azure SQL Pools**
- **Apache Spark Pools**
- **Azure Data Factory**
- **Azure Cosmos DB**
- **SQL**
- **ETL Pipelines**

## ⚙️ Key Steps & Features

### 🔧 Setup & Integration
- Provisioned and configured the **Azure Synapse Analytics** workspace
- Integrated **Data Lake Storage**, **SQL**, and **Spark pools** to enable scalable data analysis
- Connected **Azure Data Factory** for seamless data movement and ingestion

### 📥 Data Extraction
- Extracted 2021 Olympic data from **Kaggle** and other open sources
- Stored raw datasets in **Azure Data Lake** for processing

### 🔄 Data Transformation
- Cleaned and transformed datasets using **SQL queries** and **Spark notebooks**
- Converted string columns to numerical types for analysis
- Performed preliminary aggregations to explore key metrics (e.g., medals by country, sport distribution)

### 📊 Data Analysis & Insights
- Executed queries in **Synapse SQL Pools** for on-demand analytics
- Showcased analytical queries to highlight athlete performance, regional medal counts, and event trends

### 📁 Output Artifacts
| Artifact                         | Description                                      |
|----------------------------------|--------------------------------------------------|
| `olympic_raw_data.csv`          | Raw dataset extracted from Kaggle               |
| `olympic_transformed_data.parquet` | Transformed dataset used in analysis        |
| `spark_transformation_notebook.ipynb` | Spark-based data transformation logic     |
| `SQL_queries.sql`               | SQL code used in Synapse SQL Pools              |

## 🚀 Outcome
- Demonstrated the full power of **Azure Synapse** for scalable data ingestion, transformation, and querying
- Validated Azure’s capability in handling real-world analytical workloads
- Built foundational experience in cloud data engineering using Microsoft’s ecosystem
